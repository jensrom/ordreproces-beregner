# Ordreprocessens reelle pris

Interaktiv beregner til Novotek Danmarks business case om ordreprocessen (SaSMS → Salesforce → intern salg → bogføring).

- Én statisk side: `index.html` – ingen build, ingen afhængigheder.
- Datagrundlag: 42 ordrer fra SaSMS (D35383–D35424, 29-05-2026 til 05-10-2026). Kundenavne er anonymiseret.
- Alle tal kan justeres i panelet: antal sælgere, ordrer pr. dag, løn, pension, arbejdstid og minutter pr. trin.

Deploy: Vercel, uden framework (statisk).
